# Pawlio Website

The complete source for the Pawlio landing page preview.

## Files

- `index.html` — page structure and content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation interaction
- `hero.webp` — illustrated hero artwork

## Run locally

Open `index.html` in a browser. Alternatively, from this folder run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000. No dependencies, build step, backend, or database are required. Google Fonts need an internet connection; fallback fonts are used when unavailable.

The phone screen shown on the page is an illustrative mockup. The website does not contain a working download or registration integration.
